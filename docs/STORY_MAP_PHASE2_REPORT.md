## 2. 弧级评定（c 指标：包袱链完整性）

## 3. 关键发现与结论

1. **区域判据是简报最强的信号**：lull/bgm/high 三个区域与人工判断的留白/幻听/金句决策精确对应（命中率 100%）。判断层只读 `global` 段就能圈出 80% 以上的候选弧。
2. **幕级 emotion 区分度弱是预期，不是缺陷**：keep/cut 幕 emotion 均值只差 0.02-0.04，因为 judged 的 keep/cut 是词级精细决策（"这句留、那句剪"）。这正是方案的分工：**幕级信号选弧（哪段值得看），词级 text/words 细剪（弧内哪句留）**。两层不冲突、不可互相替代。
3. **边界贴合率不适用"弧骨架"定位**：P1 仅 5 幕（布局抖动合并所致），keep 段平均偏差 17s。这是正确的行为——幕是叙事弧骨架，不是词边界；judged 词级边界由弧内细剪产出。修正验收口径：以"keep 段所在幕是否被弧覆盖"为准（100%）。
4. **cut 中落在高信号区的段**（P1：停顿/间隙/碎片；P2：间隙/低语/静默）全部是"该剪的停顿"，不构成误伤——高信号区语义是"候选弧"而非"全保留"。
5. **留白弧的自动发现是新能力**：P2 两处留白（冷场 13s/9s）由 `lull_regions`+`cold_start` 自动标出，此前人工判断需听音频+看公屏才确认。这是"故事感"的直接来源：冷场是包袱链的"反应幕"，不是废料。

## 4. 对判断层工作流的修正建议

1. **读简报的顺序**：先读 `global`（区域列表）→ 再读候选弧涉及幕的 `text`/`speakers`/`emotion` → 弧内细剪时回 words/phrases 取词级边界。不必逐幕通读全部 visual。
2. **区域语义入 SKILL.md**：`lull_regions` = 留白弧（包袱反应幕），`bgm_regions` = 音乐收尾候选（需 listen 确认），`high_emotion_regions` = 金句/开场候选。已写入 Step 3.7/Step 4 叙事弧判据。
3. **P1 幕过粗时**（5 幕）：弧骨架仍可用（金句区独立），但词级边界偏差大——细剪时严格按 words 时间戳，勿用幕边界近似。
4. **回归脚本留档建议**：`_phase2_regression.py` 按需重跑（judged 更新或简报阈值调整后），输出格式即上表。
